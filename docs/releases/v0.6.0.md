# ReconcileFlow AI v0.6.0 — AI-Assisted Matching and Explainability

Version 0.6 adds advisory, explainable AI match suggestions while preserving ReconcileFlow's deterministic reconciliation engine as the authoritative execution path.

## Highlights

- Persisted, tenant-scoped advisory match suggestions with one-time review decisions
- Provider-independent inference contract with disabled-by-default operation
- Deterministic local inference for development, testing, and CI
- Privacy-minimized candidate features instead of raw financial source rows
- Strictly bounded and validated structured provider responses
- Deterministic candidate generation using amount, date, currency, and normalized reference signals
- Atomic suggestion validation and persistence with model, prompt, and configuration versions
- Authenticated generation, inspection, acceptance, and rejection APIs
- Optional OpenAI-compatible hosted inference with HTTPS, timeouts, retry limits, and response-size bounds
- Synthetic provider-independent quality evaluation with precision, recall, coverage, and calibration thresholds
- Organization opt-in, daily/monthly request limits, token limits, and pre-call quota reservations
- Privacy-safe inference lifecycle observability and tenant-isolated operational event inspection
- SQLite, PostgreSQL, Docker, and Python 3.12/3.14 validation

## Upgrade and compatibility

- Python 3.12 or newer is required.
- Run `alembic upgrade head` before starting directly installed services.
- Docker Compose applies migrations before starting the API and worker.
- Existing deterministic reconciliation and storage APIs remain compatible.
- Hosted inference remains disabled until both deployment configuration and organization policy enable it.

## Operational defaults

- The inference provider defaults to `disabled`.
- Deterministic inference requires no network connection, subscription, or API key.
- Hosted provider credentials must be supplied through environment variables or a secret manager.
- Usage reservations are created before hosted calls and released after failed calls.
- Quality evaluation uses synthetic labeled cases and aggregate reports.

## Security and privacy

AI suggestions are advisory and never replace deterministic reconciliation results automatically. Inference inputs contain bounded derived signals rather than uploaded rows or free-form business text. Usage and observability records exclude prompts, credentials, raw provider responses, source contents, and candidate identifiers. All AI records and endpoints are organization scoped. Provider errors are sanitized before persistence, logging, or API exposure.

## Current boundaries

Provider billing, model procurement, production credential rotation, custom model training, automatic acceptance of suggestions, browser interfaces, and mobile applications remain deployment or future-roadmap concerns.

All included financial and evaluation datasets are synthetic and anonymized.
