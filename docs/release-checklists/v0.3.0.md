# v0.3.0 release checklist

## Before merging

- [ ] GitHub Actions passes on Python 3.12 and 3.14
- [ ] Complete regular test suite passes
- [ ] PostgreSQL integration workflow passes after `alembic upgrade head`
- [ ] Docker API image builds successfully
- [ ] Docker Compose configuration validates
- [ ] Docker API and PostgreSQL services report healthy
- [ ] Registration, login, refresh, logout, password change, and session revocation are verified
- [ ] Login lockout and automatic recovery are verified
- [ ] Organization isolation, membership management, and RBAC are verified
- [ ] Security audit responses contain no passwords or raw tokens
- [ ] Package, FastAPI, OpenAPI, and Docker image report `0.3.0`
- [ ] No credentials, `.env` files, uploads, or real financial data are committed
- [ ] Pull request closes the final v0.3 issue

## After merging

- [ ] Update local `main` with `git pull --ff-only`
- [ ] Install the merged package with `python -m pip install --editable ".[dev]"`
- [ ] Run the complete test suite
- [ ] Start Docker Compose and confirm both services are healthy
- [ ] Confirm `GET /` and `GET /api/v1/health/ready` report version `0.3.0`
- [ ] Create annotated tag `v0.3.0`
- [ ] Push tag `v0.3.0` to GitHub
- [ ] Publish the GitHub v0.3.0 release using `docs/releases/v0.3.0.md`
- [ ] Close the `v0.3 - Authentication and Multi-Tenancy` milestone
