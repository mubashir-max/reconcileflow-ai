# v0.2.0 release checklist

## Before merging

- [ ] GitHub Actions passes on Python 3.12 and 3.14
- [ ] PostgreSQL integration test passes
- [ ] Docker API image builds successfully
- [ ] Docker Compose configuration validates
- [ ] No credentials, `.env` files, uploads, or real financial data are committed
- [ ] Pull request closes the final v0.2 issue

## After merging

- [ ] Update local `main` with `git pull --ff-only`
- [ ] Run the complete test suite
- [ ] Start Docker Compose and confirm both services are healthy
- [ ] Confirm `GET /api/v1/health/ready` returns `ready`
- [ ] Verify the documented end-to-end API workflow
- [ ] Create annotated tag `v0.2.0`
- [ ] Push tag `v0.2.0` to GitHub
- [ ] Publish the GitHub v0.2.0 release using `docs/releases/v0.2.0.md`
- [ ] Close the `v0.2 - API and Persistence` milestone
