# v0.4.0 release checklist

## Before merging

- [ ] GitHub Actions passes on Python 3.12 and 3.14
- [ ] Complete regular test suite passes
- [ ] PostgreSQL integration workflow passes after `alembic upgrade head`
- [ ] Full migration chain upgrades from an existing v0.3 database
- [ ] Docker Compose configuration validates
- [ ] API and worker images build successfully
- [ ] API, worker, and PostgreSQL services report healthy
- [ ] Asynchronous reconciliation execution completes successfully
- [ ] Scheduling, retries, cancellation, timeouts, priorities, and aging are verified
- [ ] Worker heartbeat, readiness, graceful shutdown, and stale-job recovery are verified
- [ ] Queue summaries and lifecycle-event history remain tenant-isolated
- [ ] Retention cleanup removes only expired operational records
- [ ] Public responses expose no secrets or infrastructure identifiers
- [ ] Package, FastAPI, OpenAPI, and Docker image report `0.4.0`
- [ ] No credentials, `.env` files, uploads, or real financial data are committed
- [ ] Pull request closes the final v0.4 issue

## After merging

- [ ] Update local `main` with `git pull --ff-only`
- [ ] Install the merged package with `python -m pip install --editable ".[dev]"`
- [ ] Run the complete test suite
- [ ] Start Docker Compose and confirm database, API, and worker health
- [ ] Complete one authenticated asynchronous reconciliation workflow
- [ ] Confirm `GET /` and `GET /api/v1/health/ready` report version `0.4.0`
- [ ] Confirm the Docker image label reports `0.4.0`
- [ ] Create annotated tag `v0.4.0`
- [ ] Push tag `v0.4.0` to GitHub
- [ ] Publish the GitHub v0.4.0 release using `docs/releases/v0.4.0.md`
- [ ] Close the `v0.4 - Background Processing and Job Management` milestone
