# v0.6.0 release checklist

## Before merging

- [ ] GitHub Actions passes on Python 3.12 and 3.14
- [ ] Complete regular test suite passes
- [ ] PostgreSQL integration workflow passes after `alembic upgrade head`
- [ ] Full migration chain upgrades from an existing v0.5 database
- [ ] SQLite migration upgrade and downgrade tests pass
- [ ] Docker Compose configuration validates
- [ ] API and worker images build successfully
- [ ] PostgreSQL, MinIO, API, and worker services report healthy
- [ ] Deterministic inference works without external services or credentials
- [ ] Hosted inference remains disabled by default
- [ ] Hosted configuration rejects missing credentials and unsafe endpoint URLs
- [ ] Candidate generation, suggestion persistence, and review workflows pass
- [ ] Provider output validation rejects malformed or oversized responses
- [ ] Quality evaluation thresholds pass using synthetic cases
- [ ] Organization AI enablement and request/token limits pass
- [ ] Quota is reserved before hosted inference and released after failure
- [ ] AI operational events are tenant isolated and privacy safe
- [ ] Prompts, credentials, raw responses, source text, and candidate identifiers are absent from usage and observability records
- [ ] Package, FastAPI, OpenAPI, and Docker image report `0.6.0`
- [ ] No credentials, `.env` files, uploads, or real financial data are committed
- [ ] Pull request closes the final v0.6 issue

## After merging

- [ ] Update local `main` with `git pull --ff-only`
- [ ] Install the merged package with `python -m pip install --editable ".[dev]"`
- [ ] Run the complete test suite
- [ ] Start Docker Compose and confirm PostgreSQL, MinIO, API, and worker health
- [ ] Complete one authenticated deterministic AI suggestion and review workflow
- [ ] Confirm `GET /`, OpenAPI, and `GET /api/v1/health/ready` report version `0.6.0`
- [ ] Confirm the Docker image label reports `0.6.0`
- [ ] Create annotated tag `v0.6.0`
- [ ] Push tag `v0.6.0` to GitHub
- [ ] Publish the GitHub v0.6.0 release using `docs/releases/v0.6.0.md`
- [ ] Close the `v0.6 - AI-Assisted Matching and Explainability` milestone
