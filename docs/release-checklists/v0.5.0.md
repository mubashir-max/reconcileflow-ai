# v0.5.0 release checklist

## Before merging

- [ ] GitHub Actions passes on Python 3.12 and 3.14
- [ ] Complete regular test suite passes
- [ ] PostgreSQL integration workflow passes after `alembic upgrade head`
- [ ] Full migration chain upgrades from an existing v0.4 database
- [ ] SQLite migration upgrade and downgrade tests pass
- [ ] Docker Compose configuration validates
- [ ] API and worker images build successfully
- [ ] PostgreSQL, MinIO, API, and worker services report healthy
- [ ] Local and S3-compatible provider contract tests pass
- [ ] Proxied and direct-upload workflows pass
- [ ] Direct-upload finalization rejects untrusted metadata and contents
- [ ] Presigned uploads and downloads remain short-lived and tenant-scoped
- [ ] Deletion and abandoned-upload cleanup preserve database consistency
- [ ] Quota enforcement and usage accounting pass under PostgreSQL
- [ ] Integrity verification is read-only by default
- [ ] Explicit bounded integrity repair is verified
- [ ] Cross-organization storage operations are rejected
- [ ] Logs and responses expose no credentials, signed URLs, object keys, paths, or file contents
- [ ] Package, FastAPI, OpenAPI, and Docker image report `0.5.0`
- [ ] No credentials, `.env` files, uploads, or real financial data are committed
- [ ] Pull request closes the final v0.5 issue

## After merging

- [ ] Update local `main` with `git pull --ff-only`
- [ ] Install the merged package with `python -m pip install --editable ".[dev]"`
- [ ] Run the complete test suite
- [ ] Start Docker Compose and confirm PostgreSQL, MinIO, API, and worker health
- [ ] Complete one authenticated direct-upload and asynchronous reconciliation workflow
- [ ] Run read-only storage integrity verification against the configured environment
- [ ] Confirm `GET /` and `GET /api/v1/health/ready` report version `0.5.0`
- [ ] Confirm the Docker image label reports `0.5.0`
- [ ] Create annotated tag `v0.5.0`
- [ ] Push tag `v0.5.0` to GitHub
- [ ] Publish the GitHub v0.5.0 release using `docs/releases/v0.5.0.md`
- [ ] Close the `v0.5 - Cloud Storage and File Lifecycle` milestone
