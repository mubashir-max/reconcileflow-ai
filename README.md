# ReconcileFlow AI

AI-powered financial reconciliation SaaS for matching bank transactions, ERP invoices, and payment-gateway settlements using deterministic rules, agentic AI, and human approvals.

## Current milestone

### v0.1 - Reconciliation Core

The first milestone focuses on:

- Typed financial models
- CSV and XLSX ingestion
- Deterministic reconciliation rules
- Automated tests
- Logging and input validation

## Planned architecture

- Backend: Python and FastAPI
- Database: PostgreSQL
- AI and orchestration: RAG and LangGraph
- Primary client: Flutter Web
- Later clients: Android and iOS
- Deployment: Docker and Azure

## Security

Never commit API keys, credentials, `.env` files, or real financial data.
